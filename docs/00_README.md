# Vexilian Hospitality Website Doctrine Pack

## Purpose

This folder contains the planning doctrine for the first Vexilian hospitality landing page.

The goal is to prevent GPT, Cursor, or any developer from drifting into a generic agency website, a SaaS dashboard, or a technical CRM pitch.

## Core Website Direction

Vexilian is building a Latvian-facing premium hospitality page for guest houses, event properties, pirts / sauna complexes, countryside stays, and mid-to-high hospitality operators.

The page sells one main idea:

> Vexilian helps hospitality owners find where potential clients disappear and builds a clearer path from interest to reservation.

## Non-Negotiable Positioning Rules

1. Do not present Vexilian as a website agency.
2. Do not lead with CRM, integrations, automation, infrastructure, AI, or digitalisation.
3. Do not use fake case-study numbers.
4. Do not claim percentage gains unless verified and sourced.
5. Do not make the homepage technical.
6. Do not target restaurants, cafes, bars, low-ticket businesses, or casual Airbnb hobby hosts.
7. Do not build a huge multi-page site first.
8. Do not make the hand-drawn style childish.
9. Do not overuse neon green.
10. Do not make the CTA generic.

## Correct Public Language

Use:

- klientu noplūde
- rezervāciju noplūde
- pieprasījumu ceļš
- ceļš no intereses līdz rezervācijai
- īpašnieka skats
- klusie mēneši
- tiešās rezervācijas
- veco viesu atgriešana
- no kura kanāla cilvēks atnāca
- kam jāraksta tālāk

Avoid:

- CRM implementation
- full-stack solution
- digitalizācija
- infrastruktūra
- automatizācija as the main public hook
- AI-powered
- mājaslapu izstrāde as the main offer

## Version One Scope

Version one is a landing page plus audit form.

The first page must be conversion-led, visually memorable, and commercially precise.

It must not become a large corporate website before the core offer is tested.

## Final Acceptance Question

Before launch, ask:

> Would a serious Latvian guest house, pirts complex, or event property owner feel that Vexilian understands where their reservations are leaking?

If the answer is no, the page is not ready.
