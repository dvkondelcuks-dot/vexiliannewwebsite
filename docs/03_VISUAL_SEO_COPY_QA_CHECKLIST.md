# 03_VISUAL_SEO_COPY_QA_CHECKLIST.md

## Purpose

This checklist controls the visual system, illustration planning, typography, SEO direction, copy discipline, and launch-quality review for the Vexilian hospitality homepage.

It does not cover repository structure or development tasks.

## Visual Identity Doctrine

The visual direction must preserve the existing Vexilian identity while softening it for Latvian hospitality owners.

Core Vexilian identity:

1. Dark graphite
2. Near-white
3. Neon green accent
4. Precision
5. Commercial clarity
6. System thinking
7. Premium restraint

Hospitality adaptation:

1. Warmer surfaces
2. Founder notebook feel
3. Hand-drawn SVG illustrations
4. Human commercial messiness
5. Less technical severity
6. More owner recognition
7. More seasonal and place-based context

## Colour System

Use the existing Vexilian palette as the base.

Primary:

Graphite black: `#0A0A0A`  
Near-white: `#FAFAFA`  
Neon green: `#D0FF00`

Hospitality softening colours:

Warm paper: `#F4EFE7`  
Muted sand: `#D8CBB8`  
Soft grey ink: `#8A8A8A`  
Low-contrast graphite line: `rgba(250,250,250,0.12)`

Neon green rule:

Use neon green at roughly 10 percent visual presence.

Allowed neon usage:

1. CTA highlight
2. Important leakage point
3. Small annotation mark
4. Selected path line
5. Status dot
6. Key underline
7. Audit badge

Forbidden neon usage:

1. Full backgrounds
2. Decorative overload
3. Large random glows
4. Every icon
5. Every heading
6. Hospitality imagery tinting

## Typography Direction

User-selected direction:

Open Sauce + Berthold.

Important implementation note:

If Berthold is not legally available, do not fake it and do not use unlicensed font files. Use an approved licensed alternative or system fallback.

Typography role:

1. Berthold-style font for authority, headlines, and commercial gravity
2. Open Sauce for clean modern body text and UI clarity
3. Handwritten-style font for small labels only

Typography must feel:

1. Stripe-level system clarity
2. Premium
3. Direct
4. Human but not childish
5. Commercially precise

Typography must not feel:

1. Cartoonish
2. SaaS-generic
3. Overly luxury-hotel soft
4. Decorative
5. Startup template-like

Handwritten font rule:

Use handwritten style only for:

1. Small labels
2. Annotations
3. Map notes
4. “pazūd šeit” marks
5. Founder notebook comments

Do not use handwritten font for:

1. Main headings
2. Paragraphs
3. Form labels
4. Navigation
5. Pricing
6. CTA buttons

## Copy Discipline Checklist

Before any copy is accepted, check:

1. Is it in Latvian?
2. Is it aimed at guest houses, event properties, pirts/sauna complexes?
3. Does it avoid technical talk?
4. Does it avoid saying “we build websites and CRM”?
5. Does it describe a commercial mechanism?
6. Does it make the owner recognize a real problem?
7. Does it connect to off-season reservations where relevant?
8. Does it avoid fake claims?
9. Does it avoid vague agency language?
10. Does it point toward the audit?

## Objection Handling Checklist

### Objection 1: “Mēs jau esam Booking/Airbnb.”

Answer:

> Platformas palīdz jūs atrast. Tās pašas par sevi neveido jūsu atkārtoto klientu ceļu, tiešo saziņu, sezonālos piedāvājumus un skaidru pārskatu par to, kas kļuva par rezervāciju.

### Objection 2: “Mums nevajag CRM.”

Answer:

> Jautājums nav par CRM. Jautājums ir, vai jūs zināt, no kurienes cilvēks atnāca, kurā solī viņš ir, kam jāraksta tālāk un vai viņu var uzrunāt vēlreiz.

### Objection 3: “Mums nav satura.”

Answer:

> Tad sākam nevis ar skaistām bildēm, bet ar to, kādi kadri un ziņas palīdz cilvēkam saprast vietu, iedomāties savu uzturēšanos un nonākt līdz rezervācijai.

### Objection 4: “Mums klienti nāk sezonā.”

Answer:

> Sezona bieži maskē sistēmas trūkumu. Klusie mēneši parāda, vai vietai ir savs klientu ceļš vai tikai cerība uz platformu redzamību.

### Objection 5: “Mums jau ir mājaslapa.”

Answer:

> Mājaslapa pati par sevi nav problēmas risinājums. Svarīgi ir, vai tā skaidri savieno cilvēka interesi ar pieprasījumu, atbildi, sekošanu un rezervāciju.

## SEO Strategy

SEO is secondary behind conversion quality.

Primary SEO market:

Latvia.

Primary language:

Latvian.

Primary SEO intent:

Owners searching for better reservation, booking, guest acquisition, hospitality marketing, direct booking, or sales clarity.

Do not over-optimise at the expense of premium clarity.

## Launch QA Checklist

### Positioning

1. The page does not say Vexilian is a website agency.
2. The page does not lead with technology.
3. The ICP is clearly Latvian hospitality.
4. The first screen shows messy incoming signals.
5. The page speaks to off-season bookings.
6. The CTA is diagnostic.
7. The offer feels selective.

### Copy

1. Copy is Latvian.
2. Copy is direct and premium.
3. Copy avoids banned words.
4. Copy answers Booking/Airbnb objection.
5. Copy answers “we do not need CRM.”
6. Copy avoids fake proof.
7. Copy avoids generic agency phrases.
8. Copy contains concrete owner situations.

### Visuals

1. Hand-drawn feel is present but controlled.
2. Neon green is around 10 percent.
3. Illustrations explain the commercial story.
4. Typography is clean and authoritative.
5. Handwritten font is used only for annotations.
6. No cartoon or childish elements.
7. No generic SaaS hero dashboard.

### SEO

1. H1 contains the core problem.
2. Metadata is Latvian.
3. SEO keywords are natural.
4. Page supports Latvian hospitality search intent.
5. Future content plan exists.
6. No unsupported statistics are used.

### Conversion

1. CTA is visible above the fold.
2. CTA repeats after major sections.
3. Form asks enough to score lead quality.
4. Form does not feel too long.
5. Thank-you message sets expectation.
6. Follow-up promise is clear.
7. Pricing direction filters weak leads.

## Final Acceptance Question

Would a serious Latvian guest house, pirts complex, or event property owner think:

> They understand where my reservations are leaking.

If no, the page is not ready.
