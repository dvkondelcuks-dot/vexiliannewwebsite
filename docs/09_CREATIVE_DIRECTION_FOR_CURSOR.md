# 09_CREATIVE_DIRECTION_FOR_CURSOR.md

## Purpose

This document is the compact creative direction file that Cursor or GPT should read immediately before creating any visual layout, homepage design, or copy implementation.

It exists to prevent design drift.

This is not a repository build guide.

## One-Sentence Direction

Create a premium Latvian hospitality landing page that feels like a founder’s commercial notebook mapping where reservations leak between first interest and confirmed booking.

## Product Being Sold

Do not sell websites.

Sell:

> the ability to find where clients disappear and create a clearer path from interest to reservation.

Main offer:

> Vexilian Klientu Noplūdes Audits

Commercial system:

> Vexilian Rezervāciju Noplūdes Sistēma

## Audience

Build for:

1. Latvian guest house owners
2. Pirts / sauna complex owners
3. Event property owners
4. Countryside hospitality operators
5. Hands-on owners who have worked manually for years and are not digitally/systematically mature

Do not build for:

1. Restaurants
2. Cafes
3. Bars
4. Cheap website buyers
5. Casual Airbnb hobby hosts
6. Generic business owners

## Core Story

Start with five messy incoming signals:

1. Instagram DM
2. Booking request
3. Calls
4. Emails
5. Website forms

Then show:

1. Interest is not reservation.
2. Clients leak across the path.
3. Off-season months expose the weakness.
4. Booking/Airbnb are useful but incomplete.
5. Vexilian diagnoses the leakage.
6. The owner gets clarity and next actions.
7. The audit is the first step.

## Emotional Arc

Beginning:

Slight chaos, scattered signals, owner recognition.

Middle:

Clear diagnosis, leakage path, off-season pressure.

End:

Control, selectivity, audit CTA.

## Visual Mood

Use:

1. Dark graphite foundation
2. Warm paper panels
3. Hand-drawn SVG arrows and notes
4. Neon green as precision accent only
5. Hospitality-specific icons
6. Premium spacing
7. Controlled chaos in hero
8. Calm clarity in later sections

Do not use:

1. Generic SaaS dashboard hero
2. Cartoon doodles
3. Random icons
4. Fake hotel renders
5. Overused laptop mockups
6. Big 3D blobs
7. Template agency sections
8. Excessive neon

## Color Direction

Base:

`#0A0A0A`

Text:

`#FAFAFA`

Accent:

`#D0FF00`

Warm paper:

`#F4EFE7`

Muted sand:

`#D8CBB8`

Neon green must be around 10 percent visual presence.

Use neon green for:

1. CTA accent
2. Key leakage mark
3. Active path
4. Status dot
5. Small underline

Do not use neon green as the main background.

## Typography Direction

Preferred:

1. Open Sauce for body/UI
2. Berthold-style font for headings if legally available
3. Handwritten-style font for tiny annotations only

Important:

Do not use unlicensed Berthold font files. If unavailable, use a legal substitute.

Typography should feel:

1. Stripe-level clear
2. Commercial
3. Premium
4. Sharp
5. Calm

Handwritten font only for:

1. “pazūd šeit”
2. “nav follow-up”
3. “klusais mēnesis”
4. “kurš kanāls?”
5. small visual notes

Never use handwritten font for:

1. H1
2. H2
3. body text
4. buttons
5. forms
6. pricing

## Layout Feel

The page should feel:

1. Strong above the fold
2. Short but not thin
3. Editorial but systemised
4. Premium but practical
5. Clear enough for a business owner
6. Visual enough to be memorable

Avoid:

1. Long corporate blocks
2. Generic service grids
3. Too many columns
4. Overloaded animations
5. Random testimonials
6. Fake proof

## Section Order

Use this order:

1. Hero with messy signals
2. Pieprasījums is not reservation
3. Leakage path
4. Off-season problem
5. Booking/Airbnb reframe
6. Vexilian method
7. Owner control view
8. Use cases
9. Pricing/selectivity
10. Final audit CTA and form
11. Footer

Do not add unrelated sections.

## Copy Rules

Write only in Latvian.

Do not use:

1. digitalizācija
2. infrastruktūra
3. CRM as public hook
4. integrācijas
5. automatizācija as public hook
6. AI-powered
7. full-stack
8. mājaslapu izstrāde as main offer
9. moderni risinājumi
10. 360 grādu pieeja
11. garantēti rezultāti
12. generic agency language

Use instead:

1. pieprasījumu ceļš
2. klientu noplūde
3. rezervāciju noplūde
4. īpašnieka skats
5. kam jāraksta tālāk
6. no kura kanāla cilvēks atnāca
7. ceļš no intereses līdz rezervācijai
8. veco viesu atgriešana
9. klusie mēneši
10. tiešās rezervācijas

## Primary Copy

H1:

> Jūsu viesi raksta no visurienes. Bet kur pazūd rezervācijas?

Subheadline:

> Vexilian palīdz viesu namiem, pirts kompleksiem un pasākumu vietām atrast, kur cilvēki pazūd starp pirmo interesi un rezervāciju, un sakārtot skaidrāku ceļu līdz apstiprinātam klientam.

Primary CTA:

> Noskaidrojiet, kur jums pazūd klienti

Secondary CTA:

> Apskatīt noplūdes piemērus

## Illustration Rules

The homepage must include these visual ideas:

1. Messy signal cards
2. Broken reservation path
3. Off-season calendar
4. Platform dependence split
5. Owner control board
6. Hospitality use-case cards
7. Audit note next to form

Each illustration must explain the section.

Do not include decorative illustrations that do not clarify leakage.

## Animation Direction

Allowed:

1. Signal cards gently float
2. Drawn path animates softly
3. Leakage mark appears
4. Cards reveal gently
5. CTA accent has subtle motion

Avoid:

1. Scroll hijacking
2. Rapid motion
3. Bounce effects
4. Spin effects
5. Excessive parallax
6. Over-animated hero

Respect reduced motion.

## Homepage Quality Bar

The page should feel closer to:

1. Stripe-level system clarity
2. Premium founder notebook
3. Commercial diagnostic page
4. Baltic hospitality operator intelligence

Not:

1. Webflow agency template
2. SaaS analytics dashboard
3. Luxury hotel brochure
4. Cartoon sketch site
5. AI automation agency page

## Conversion Rules

Primary CTA must appear:

1. Hero
2. After leakage explanation
3. Before or after method
4. Final form section

CTA language must stay diagnostic.

Do not use:

1. Contact us
2. Let's talk
3. Get started
4. Learn more as primary CTA
5. Send message

Use:

1. Noskaidrojiet, kur jums pazūd klienti
2. Pieteikt bezmaksas auditu
3. Pārbaudīt rezervāciju noplūdi

## Proof Rules

Do not create fake proof.

Allowed:

1. Process clarity
2. Diagnostic logic
3. Certifications if mentioned carefully
4. Future hospitality direction
5. Example leakage scenarios

Not allowed:

1. Fake revenue numbers
2. Fake case studies
3. Fake testimonials
4. Unsupported percentage gains
5. Completed Purgaiļi result claims

## Cursor Pre-Design Instruction

Before generating any visual or UI, Cursor must summarize:

1. ICP
2. Core problem
3. Main offer
4. Homepage section order
5. Visual style
6. Copy restrictions
7. Illustration requirements
8. SEO direction
9. Conversion goal

Then it must ask for approval before proceeding.

## Final Creative QA

Before accepting any generated design, ask:

1. Does it immediately speak to Latvian hospitality owners?
2. Does the hero show messy incoming signals?
3. Does it avoid technical language?
4. Does it avoid website-agency positioning?
5. Does it show off-season leakage?
6. Does it answer Booking/Airbnb dependence?
7. Does it feel premium, not childish?
8. Are the illustrations explanatory?
9. Is neon green controlled?
10. Is the CTA diagnostic?
11. Is the form an audit form, not a contact form?
12. Would a serious owner understand the value in 5 seconds?

If any answer is no, revise before building.
