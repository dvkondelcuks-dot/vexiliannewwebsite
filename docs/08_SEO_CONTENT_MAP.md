# 08_SEO_CONTENT_MAP.md

## Purpose

This document defines SEO planning for the first Vexilian hospitality landing page and future Latvian hospitality authority content.

SEO is secondary behind conversion quality.

The first page must convert serious owners before it tries to rank for every keyword.

## SEO Positioning

Vexilian should not compete as a generic “marketing agency” or “website developer.”

Vexilian should build a sharper Latvian search position around:

1. klientu noplūde
2. rezervāciju noplūde
3. tiešās rezervācijas
4. viesu nama klientu piesaiste
5. pirts kompleksa klientu piesaiste
6. pasākumu vietas pieprasījumi
7. klusie mēneši
8. Booking/Airbnb dependence
9. hospitality pārdošanas ceļš
10. ceļš no intereses līdz rezervācijai

## Primary SEO Audience

Latvian hospitality owners searching for:

1. more reservations
2. direct bookings
3. off-season guests
4. marketing for guest houses
5. better booking flow
6. less dependence on platforms
7. better follow-up
8. better enquiry management

The page should not chase international hospitality SaaS searches.

## Primary Language

Latvian only for version one.

Do not mix English into page copy unless it is already common in the market, such as Booking, Airbnb, follow-up, or hospitality.

## Homepage SEO Target

The homepage should own the concept:

> Klientu noplūdes audits hospitality vietām Latvijā

It should not try to be:

1. “best website agency Latvia”
2. “CRM implementation Latvia”
3. “AI automation agency Latvia”
4. “hotel marketing agency” in a generic way

## Keyword Usage Rules

1. Use keywords as concepts, not forced phrases.
2. Prioritise clarity over keyword density.
3. Do not make copy sound like an SEO article.
4. Include “viesu nami,” “pirts kompleksi,” and “pasākumu vietas” naturally.
5. Use “rezervācija” more often than “lead.”
6. Use “pieprasījums” instead of “lead.”
7. Use “īpašnieka skats” instead of “dashboard.”
8. Use “ceļš līdz rezervācijai” instead of “sales funnel.”

## FAQ Ideas for Future Homepage or Expansion

FAQ 1:

> Mēs jau esam Booking un Airbnb. Kāpēc ar to nepietiek?

Answer direction:

Platforms help visibility, but do not replace the owner’s own repeat-guest path, direct communication, follow-up, and source visibility.

FAQ 2:

> Vai tas nozīmē, ka mums obligāti vajag jaunu mājaslapu?

Answer direction:

Not necessarily. First Vexilian checks where the leakage is. Sometimes the problem is content, follow-up, offer structure, or lack of visibility.

FAQ 3:

> Mums nav sakārtots saturs. Vai var sākt tāpat?

Answer direction:

Yes. The audit can identify what content is missing and what visuals/messages are needed to move people toward reservation.

FAQ 4:

> Vai audits ir bez maksas?

Answer direction:

The initial client leakage audit is free for selected hospitality businesses that match Vexilian’s scope.

FAQ 5:

> Ko mēs redzēsim pēc audita?

Answer direction:

Where enquiries come from, where they likely disappear, what weak months need attention, and what should be fixed first.

## Source and Statistics Rule

No public percentage claims without verification.

If using market data later, sources should be:

1. Official Latvian tourism data
2. Central Statistical Bureau of Latvia
3. Investment and Development Agency of Latvia tourism materials
4. Eurostat when relevant
5. Booking/hospitality industry reports if accessible and current
6. Reputable hospitality research sources

Every statistic must answer:

1. Is it current?
2. Is it Latvia-relevant?
3. Does it apply to this ICP?
4. Does it support the specific claim?
5. Is it necessary for conversion?

If not, omit it.
